## Installation

1. Clone the repostory `git clone https://github.com/eviveraart/TTTools.git`
1. Update the submodule `git submodule init` and `git submodule update`
1. Install [Node.js](https://nodejs.org/en/download/)
1. Build the site, run `npm i`
1. Serve the site `npm run serve:dev`

See [the official install guide](https://wiki.tercept.net/en/5eTools/InstallGuide) for more info.
